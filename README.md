# FirstGameOfPomg

A simple single-player Pong game built with HTML, CSS, and JavaScript.

## How to run in GitHub Codespaces

1. Open the repository in GitHub Codespaces.
2. Open a terminal in the project root.
3. Start a local web server:

   ```bash
   cd /workspaces/FirstGameOfPomg
   python3 -m http.server 8000
   ```
4. In the browser, open the forwarded port preview for port 8000.
5. Visit:

   ```text
   http://localhost:8000/index.html
   ```

## How to run locally

1. Open a terminal in the project folder.
2. Start the app with:

   ```bash
   cd /path/to/FirstGameOfPomg
   python3 -m http.server 8000
   ```
3. Open your browser and go to:

   ```text
   http://localhost:8000/index.html
   ```

## Controls

- Player paddle: W / S
- Player paddle alternate: Up / Down Arrow
- Goal: keep the ball away from your side and score against the computer

## Game features

- Black background with white ball and paddles
- White center line
- Single-player mode against the computer
- Paddle movement only in the vertical direction
